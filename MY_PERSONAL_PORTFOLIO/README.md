## 📌 Overview

This repository contains the personal portfolio website of **Sanika Yogesh Mahajan**, crafted to showcase frontend web development capabilities, project case studies, and hands-on skills acquired during the **CodeAlpha Internship**.

Built with a modern, high-contrast **Light Theme** aesthetic, this site also features an optional **Dark Mode Switch**, interactive project showcases, live resume modal with print/PDF support, and accessible form validations.

---

## ✨ Features & Highlights

- 🎨 **Modern Light Theme Aesthetic**: Clean typography (*Plus Jakarta Sans* & *Space Grotesk*), harmonious gradients, subtle mesh glows, and micro-interactions.
- 🌓 **One-Click Theme Toggle**: Instant transition between Light and Dark mode with `localStorage` persistence.
- ⌨️ **Dynamic Typing Animation**: Smooth typing and backspacing effect showcasing developer roles.
- 📱 **100% Fully Responsive**: Mobile-first design adapting seamlessly from 360px phones to 4K displays.
- 🗂️ **Filterable Projects Showcase**: Categorize projects by *Web Apps*, *JavaScript*, and *CodeAlpha Tasks*.
- 🔍 **Interactive Project Modal**: Quick view case studies with implementation details and tech tags.
- 📄 **Integrated Resume Preview & Print**: In-browser printable/PDF-exportable resume preview modal.
- 📬 **Interactive Contact Form**: Real-time accessible client-side form validation (`:user-valid`/`:user-invalid`) and custom toast feedback.
- 📋 **One-Click Email Copy**: Direct copy to clipboard with instant confirmation toast.

## 🚀 How to Run Locally

You don't need any complex build tools or dependencies! Simply follow these steps:

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/your-username/codealpha_tasks.git
   cd MY_PERSONAL_PORTFOLIO
   ```

2. **Open with any browser:**
   - Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
   - **OR** with VS Code Live Server extension: Right click `index.html` -> *Open with Live Server*.
   - **OR** with Python local server:
     ```bash
     python -m http.server 3000
     ```
     Then navigate to `http://localhost:3000` in your browser.

## 🌐 How to Deploy to GitHub Pages (For CodeAlpha Submission)

1. Initialize a git repository and commit your files:
   ```bash
   git init
   git add .
   git commit -m "feat: complete modern portfolio for CodeAlpha internship"
   ```
2. Create a new repository on your GitHub account named `CodeAlpha_Frontend_Portfolio`.
3. Push your code:
   ```bash
   git remote add origin https://github.com/<your-username>/CodeAlpha_Frontend_Portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Branch**, select `main` and root `/ (root)`.
   - Click **Save**.
   - Within 1-2 minutes, GitHub will provide your live URL: `https://<your-username>.github.io/CodeAlpha_Frontend_Portfolio/`.
